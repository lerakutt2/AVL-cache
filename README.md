# diplom
## Как запустить программу
*Примечание.* Способы не тестировались, но работают локально (у меня на компьютере), поэтому высокая вероятность возникновения неполадок.

**Для запуска программы необходимо положить [файл ggParameters.txt](https://disk.jinr.ru/index.php/s/QAx8i5BmMXJRdkY) в основную директорию проекта
### 1 способ. Linux
1. Открыть терминал Linux (или WSL)
2. Перейти в директорию проекта
3. Ввести следующие команды

```
mkdir -p build
cd build
cmake ..
make
./diplom_new
```
5. Далее можно запускать командами
```
make
./diplom_new
```
### 2 способ. Visual Studio
1. Открыть папку проекта с помощью Visual Studio
2. Запустить (F5)

## Что умеет программа
Данная программа предоставляет реализацию гетерогенного связанного списка деревьев для хранения вызовов функций. Данная структура подходит для функции с входными параметрами любого численного типа (возможно, для любого типа, но это нуждается в тестировании), кроме ссылочных, и любым типом выходного параметра. Для создания
списка деревьев для функции используется

```cpp
TreeList my_tree_list(your_function);
```

Вместо обычного вызова функции теперь можно использовать

```cpp
my_tree_list.GetValue(param1, param2, param3); // и так далее
```
